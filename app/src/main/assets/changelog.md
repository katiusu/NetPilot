## 2.0.1

- 修复版本比较：2.0.0-rc.3 这类预发布版不再被判定为比 2.0.0 更新，仓库把 rc 标成正式 Release 时不会再提示「有新版本」实为降级。
- 修复「预测性返回」开关无效：之前反射的是 Window 上根本不存在的方法，异常还被静默吞掉；改为反射 Activity 的实现，系统不允许时写一条诊断日志。
- 修复切回「跟随系统」语言后不还原：进程默认语言会停在上一门语言上，影响排序与日期格式化。
- 修复配置导入在文件不可读时的空指针：改为安全读取并记录真实原因，不再笼统提示「导入失败」，同时不再泄漏输入流。
- 修复配置导入遇到含非字符串元素的数组时整份失败：现在跳过无法识别的项继续导入。
- 新增联发科实验通道（默认关闭）：开启后，在系统通道全部失效时绕过 framework 直接向 modem 写制式（AT+ERAT），写完立即回读确认；写前先读当前制式，已是目标集合就不重复写（MTK 的 RIL 会吞掉同值写，硬写只会拿到旧回读）。
- 设置页新增「AT 直写（联发科实验）」开关与「测试 AT 通道」：探测先对 rild-atci 发一次 AT 握手，再读 AT+ERAT=? 与 AT+ERAT? 判断可读可写。
- 已知限制：该通道只支持 root（Shizuku 的 shell uid 连不上 gsmrild_socket）；只操作当前默认数据卡所在的卡槽；重启后 modem 会被运营商配置改回；framework 侧的制式显示不会同步。


## 2.0.0

- 安全：Tasker 写类命令必须带 netpilot.token；回执与状态广播只发给已安装的 Tasker；Locale 插件入口加来源白名单。
- 「停止监控」现在真的停下：停止后冷启动、开机自启与系统拉起都不会再开启监控。
- 降级不再丢记录：写回失败保留原制式并退避重试，进程被杀也不再忘记；息屏跳过探测不再被误判成「网络无响应」。
- 副卡改制式写对键并回读确认；从未设置过主卡时不再误判「已在家卡」；规则冷却按「规则 + 目标卡」分别计时，换 Wi-Fi 后立刻生效。
- 特权命令读取带超时，通道卡住时设置页与磁贴不再无响应；通道探测不再阻塞制式读写；隐藏 API 豁免失败可以重试。
- 切换数据卡改为回读校验，没真正切过去就如实报失败。
- 新功能：基带只读探测，只识别不写入。
- 设置页可查看本版本更新日志。

## 2.0.0-rc.3

- 对外接口加固：Tasker 命令校验口令，未知 action 一律拒绝；回执与事件广播改为定向发送，找不到目标时不再带信号数据；Locale 插件入口加来源白名单。
- 「停止监控」被系统拉起的问题修复：服务 onCreate 不再无条件认为用户想监控。
- 降级写回失败不再丢弃记录，改为保留并退避重试（最多 3 次），到上限写入原因后停止重试。
- 息屏跳过探测不再算作网络无响应，避免误触无网回滚。
- 监控循环与手动采样加互斥，通知文本改为发送成功后才缓存。
- settings 兜底写制式按 subId 映射到正确的键并回读确认，映射不出来直接失败。
- 子进程命令读取加超时，读线程与等待共用预算，超时强制结束并返回已读部分。
- 制式记忆合成不可变对象，消除三个 volatile 字段的撕裂读。
- 通道探测移出主锁，探测期间不再阻塞制式读写；隐藏 API 豁免失败可重试。
- 切换数据卡对 void 返回的反射方法改为回读校验，已是目标卡时短路。
- 双卡：homeSubId 改为未设置哨兵并做一次性迁移，导出备份不再写哨兵，恢复时视为删除该键。
- 降级前的制式记录改为持久化，进程被杀不再丢失；规则冷却按「规则 + 目标卡」独立计时，全局只留 5 秒防抖。
- 亮灭屏重排闹钟加节流规则，频繁亮灭屏不再饿死心跳；配置导入后通知观察者，policies 空数组语义统一为「清空」。
- 新增基带只读探测：按系统属性、特征文件与 ServiceManager 三级判据识别平台，只读不写。
