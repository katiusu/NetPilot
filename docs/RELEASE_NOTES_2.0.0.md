# NetPilot 2.0.0

- versionName **2.0.0** / versionCode **23**
- 上一版：1.6.0（versionCode 2026101800）
- 跨度：2.0.0-rc.1 → 2.0.0-rc.2 → 2.0.0-rc.3 → 2.0.0

## ⚠️ 升级前必读

- **包名已改**：`com.katiusu.netpilot` → `io.github.katiusu.netpilot`（自 rc.1）。系统视为两个独立应用，新旧版本会并存 —— 装好新版后请手动卸载旧版，不要期待覆盖安装。
- **需要重新绑定的东西**：Tasker 任务、Locale 插件条件、快捷设置磁贴、桌面快捷方式。包名变了，旧引用全部失效。
- **Tasker 写类命令现在必须带口令**（自 rc.3）：在功能页开启 Tasker 接口时生成随机口令，脚本里把它放进 `netpilot.token` 这个 extra；只读命令（`SAMPLE_NOW` / `GET_STATUS`）不需要。详见 `docs/TASKER.md` §3.4。
- **minSdk 34 → 33**（targetSdk 36 不变）。

## 界面重构

- 升级到 Miuix 0.9.5-beta02，整站换成 MiuixExample 骨架：统一顶栏、分区卡片、二级页、搜索浮层与统一动效。
- 主页信息重新分层；快速操作收进二级页。
- 底栏样式可选**柔光玻璃** / **液态玻璃**；宽屏下可用侧栏（无 / 顶部 / 左侧）替代底栏。
- 新增**预测性返回**开关（默认开）：走 `setEnableOnBackInvokedCallback` 反射，厂商裁剪该方法时安静降级为「没有预览动画」，返回手势本身不受影响。
- 背景模糊与玻璃浮层统一走宿主 backdrop；新增 TopLayer，让页面内浮层（如日志页溢出菜单）也用玻璃材质，窗口菜单保留为回落分支。
- 连续曲率圆角（graphics-shapes 1.1.0），三套主题下不再出现接缝。
- 下拉菜单改为玻璃卡片形式，与整体风格统一。
- 关于页重构为两节并修掉偶发闪退。
- 新增**繁体中文**（values-zh-rTW 全量 720 条文案）。

## 安全与对外接口

- Tasker 命令广播加口令校验，不在白名单里的 action 一律拒绝（fail-closed）。
- 回执与事件广播（降级 / 恢复 / 制式变更 / 换卡 / 采样）改为定向发送；找不到已安装的 Tasker 时不再附带 RSRP / SINR / Ping / 通道名。
- Locale 插件入口加来源白名单（Tasker 两个包名 + `com.android.shell`），不可信来源在解析 Bundle 之前就拒绝。

## 监控与降级状态机

- **「停止监控」真的停**：服务 onCreate 不再无条件认为用户想监控；新增持久化标记，冷启动对账与开机自启都先看它。
- **写回失败不再丢记录**：保留原制式、退避重试最多 3 次；降级前的制式改为持久化，进程被杀也不再忘记。
- 息屏跳过探测不再算「网络无响应」，避免误触无网回滚。
- 监控循环与手动采样加互斥，消除两个 tick 并发写状态机。
- 通知文本改为发送成功后才缓存，同一条提醒不会因为一次失败而永久静默。
- 日志列表改用 StateFlow 订阅，后台线程写入也能触发重组。

## 特权通道

- settings 兜底写制式按 subId 映射到正确的键（副卡写 `preferred_network_mode1`）并回读确认，映射不出来直接失败而不是猜键。
- 子进程读取加超时：读线程与 `waitFor` 共用 5 秒预算，超时 `destroyForcibly` 并返回已读部分。
- 制式记忆合成不可变对象，消除三个 volatile 字段的撕裂读；通道探测移出主锁，探测期间不再阻塞读写。
- 隐藏 API 豁免失败不再被永久缓存，可以重试。
- 切换数据卡改为回读校验，没真正切过去就如实报失败；已是目标卡时短路。

## 双卡与 Wi-Fi 策略

- `homeSubId` 改为未设置哨兵（-1）+ 一次性迁移，修掉「从未设置过主卡」时的死循环；备份导出不再写哨兵，恢复时视为删除该键。
- 规则冷却改为按「规则 + 目标卡」独立计时，全局只留 5 秒防抖 —— 一张卡的冷却不再挡住另一张卡。
- 写制式的节流时间戳语义改为「上次尝试」，失败也记，避免失败后下一轮立刻再 fork 一次特权进程。
- 非活跃数据卡自动降到 4G（次卡）自 1.6.0 起保留。

## 保活与配置

- 亮灭屏重排闹钟加三条规则 + 30 秒节流：闹钟不存在必排、状态没变不动、真变了且超 30 秒才排。频繁亮灭屏不再饿死 15 分钟心跳。
- 配置导入后通知观察者，Tasker 组件启停等系统侧会同步。
- 配置备份的 policies 空数组语义统一为「清空」，与 rules 对齐。

## 新功能

- **基带只读探测**：按「系统属性 → 特征文件存在性 → ServiceManager 是否注册 `phoneEx`」三级判据识别高通 / 联发科 / 三星 / 紫光 / 未知，带置信度与证据链，结果缓存 7 天。本版只识别不写入 —— 不 open 任何 `/dev` 节点、不发任何 AT 指令（那是 RIL 独占的 modem 串口）。
- **内置更新日志**：设置页可直接查看当前版本的更新说明，不必去仓库翻。
- 设置页新增「检查更新」入口，关于页保留快捷入口。

## 构建与发布

- 构建迁到 GitHub Actions；CI 直接产出 **release 签名** 包（密钥只存 secrets，不入库），可覆盖安装后续 CI 包。
- `compileSdk 37.2`（Miuix 0.9.5 AAR 元数据要求）· `targetSdk 36` · `minSdk 33` · Kotlin 2.4.20 · R8 开启。
- CI 跳过阿里云镜像、直连 google() / mavenCentral()（阿里云返回 502 时 Gradle 不会优雅降级，会让整批依赖失败）。

## 已知限制

- 降级写回失败到重试上限后，界面仍显示「降级中」，只在日志里写明「写回已停止重试，请手动恢复」。
- 用户「停止」监控后，设置页的自动降级开关仍显示为开启（服务确实不跑）。
- 两个 Tasker receiver 仍是 `exported=true` 且无 signature 权限：能挡住改状态，挡不住同机 App 用一条广播唤醒进程。
- 基带探测的联发科分支未在真机验证（开发机是高通平台），只能靠用户回传日志。
- RuntimeShader 不可用的机型上，玻璃组件由库内回落到普通样式，外观会退化但不会崩。
